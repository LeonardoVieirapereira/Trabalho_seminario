Aula 32 & 33: Manipulação de Strings e Listas

Estilo Noturno & Tecnológico

Manipulação de Strings

Strings são sequências de caracteres usadas para tratar textos.

  • .find() / .indexOf(): Busca posições de letras ou palavras.
  • .count(): Conta ocorrências de caracteres.
  • .upper() / .lower(): Converte maiúsculas e minúsculas.
  • .replace(): Substitui termos específicos no texto.

Estrutura de Listas

Listas são coleções mutáveis que armazenam dados dinâmicos.

  • Usadas para guardar o progresso de jogos (ex: Jogo da Forca).
  • Permitem adicionar e remover itens dinamicamente.
  • Exemplo em Python: .append() e .remove()

Exemplo Prático

Exemplo de inserção de itens em lista:

// Python: lista.append("A")
// C++: lista.push_back("A");
// Java: lista.add("A");

Conclusão

Manipular Strings e Listas é essencial para criar algoritmos eficientes, analisar dados e construir jogos interativos.
