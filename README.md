# Seminário: Manipulação de Strings e Listas

Repositório criado para demonstrar os conceitos de manipulação de strings e vetores/listas aplicados em **C++**, **Java** e **HTML/JavaScript**.

## 📁 Estrutura do Projeto

- `/cplusplus/manipulacao_listas.cpp`: Implementação de busca de substring e `std::vector` em C++.
- `/java/ManipulacaoListas.java`: Manipulação de `String` e uso de `ArrayList` em Java.
- `index.html`: Interface web para testes visuais e interativos de manipulação de strings e arrays em JavaScript.

## 🚀 Como Executar

### C++
```bash
g++ cplusplus/manipulacao_listas.cpp -o manipulacao
./manipulacao
