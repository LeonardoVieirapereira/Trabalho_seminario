Aula 32: Principais Métodos de Strings

  • .find() / .indexOf(): Retorna o índice numérico da primeira ocorrência.
  • .count(): Calcula a frequência exata de um caractere ou palavra.
  • .upper() & .lower(): Converte a string para maiúsculas ou minúsculas.
  • .replace(antigo, novo): Substitui sequências de texto por novos valores.

❓ Pergunta da Aula:

Qual função substitui todas as ocorrências de "Python" por "JavaScript"?

✔ O método .replace("Python", "JavaScript").

Exemplo Prático em Python (Strings)

texto = "Desenvolvimento de Sistemas"

print(texto.find("Sistemas"))        # Saída: 19
print(texto.count("e"))               # Saída: 5
print(texto.upper())                 # Saída: DESENVOLVIMENTO DE SISTEMAS
print(texto.replace("Sistemas", "Web")) # Saída: Desenvolvimento de Web

❓ Qual é a saída?

O que o código print("aula".upper()) exibe no console?

✔ Exibe: AULA (em letras maiúsculas).

Comparativo de Strings: Java & C++

// --- JAVA ---
String texto = "Desenvolvimento de Sistemas";
int pos = texto.indexOf("Sistemas"); // 19
String novo = texto.replace("Sistemas", "Web");

// --- C++ ---
#include <string>
std::string texto = "Desenvolvimento de Sistemas";
size_t pos = texto.find("Sistemas"); // 19
texto.replace(pos, 8, "Web");

❓ Comparativo:

Qual o equivalente do método .find() do Python na linguagem Java?

✔ O método .indexOf().

Aula 33: Estruturas de Dados (Listas)

O Desafio de Isabele (Jogo da Forca): Armazenar e atualizar o progresso de um jogo sem alterar a palavra secreta original.

  • Listas em Python: Coleções mutáveis e dinâmicas.
  • Índices: Cada elemento possui uma posição que começa em 0.
  • Progresso: Substituir underscores (_) pelas letras acertadas.

❓ Pergunta sobre Listas:

O que significa dizer que uma lista em Python é "mutável"?

✔ Significa que seus elementos podem ser alterados, adicionados ou removidos após a criação.

Lógica do Jogo da Forca com Listas

1. Inicialização com Underscores:
   palavra_secreta = "python"
   progresso = ['_', '_', '_', '_', '_', '_']

2. O jogador adivinha a letra 'p' (Índice 0):
   progresso[0] = 'p' -> ['p', '_', '_', '_', '_', '_']

3. O jogador adivinha a letra 'o' (Índice 4):
   progresso[4] = 'o' -> ['p', '_', '_', '_', 'o', '_']

❓ Teste de Lógica:

Se a palavra é "gato" e o jogador acertou a letra 't', qual o valor do índice 2?

✔ O valor é 't' (pois os índices são 0:'g', 1:'a', 2:'t', 3:'o').

Métodos Cruciais para Listas em Python

  • .append(item): Adiciona um novo elemento ao final da lista.
  • .remove(item): Remove a primeira ocorrência do valor especificado.
  • .sort(): Reorganiza os elementos em ordem crescente/alfabética.
  • len(lista): Retorna a quantidade total de elementos.

❓ Pergunta da Aula 33:

Qual método usamos para adicionar uma nova letra acertada na lista?

✔ O método .append('letra').

Exemplo Prático em Python (Listas)

letras_acertadas = []

letras_acertadas.append('p')
letras_acertadas.append('y')
print("Acertos:", letras_acertadas) # Saída: ['p', 'y']

palavra_secreta = "python"
tentativa = input("Digite uma letra: ").lower()

if tentativa in palavra_secreta:
    letras_acertadas.append(tentativa)

❓ Pergunta de Código:

Como verificar em Python se uma letra tentada está dentro da palavra secreta?

✔ Usando o operador "in": if tentativa in palavra_secreta:

Listas Dinâmicas em Java (ArrayList)

import java.util.ArrayList;

public class JogoForca {
    public static void main(String[] args) {
        ArrayList<String> letrasAcertadas = new ArrayList<>();

        letrasAcertadas.add("p");
        letrasAcertadas.add("y");

        System.out.println("Progresso: " + letrasAcertadas);
    }
}

❓ Pergunta de Java:

Qual classe é utilizada em Java para criar listas com tamanho dinâmico?

✔ A classe ArrayList.

Listas Dinâmicas em C++ (std::vector)

#include <iostream>
#include <vector>
#include <string>

int main() {
    std::vector<std::string> letrasAcertadas;

    letrasAcertadas.push_back("p");
    letrasAcertadas.push_back("y");

    std::cout << "Tamanho: " << letrasAcertadas.size();
    return 0;
}

❓ Pergunta de C++:

Qual o comando usado em C++ para adicionar um item no final de um vector?

✔ O comando push_back().
