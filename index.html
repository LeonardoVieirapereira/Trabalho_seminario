Aula 32: O Desafio de Carlos

Carlos precisa extrair informações de um texto e contar a frequência de palavras/letras.

  • Solução: Usar o método count() para contar ocorrências.
  • Usar find() ou index() para achar a posição da letra.
  • Usar split() para separar as palavras.

Aula 32: Funções de String em Python

  • .find(): Retorna o índice da primeira ocorrência.
  • .count(): Conta quantas vezes a letra aparece.
  • .upper() / .lower(): Converte para maiúsculo/minúsculo.
  • .replace(): Substitui trechos de texto.

Exemplo Prático de Strings (Python)

texto = "Olá, mundo!"
print(texto.find("mundo"))  # Saída: 5
print(texto.count("o"))      # Saída: 2
print(texto.upper())        # Saída: OLÁ, MUNDO!
print(texto.replace("Olá", "Adeus")) # Saída: Adeus, mundo!

Exemplo Prático de Strings em Java

public class StringsJava {
    public static void main(String[] args) {
        String texto = "Olá, mundo!";
        System.out.println(texto.indexOf("mundo")); // Saída: 5
        System.out.println(texto.toUpperCase());   // OLÁ, MUNDO!
        System.out.println(texto.replace("Olá", "Adeus"));
    }
}

Exemplo Prático de Strings em C++

#include <iostream>
#include <string>
using namespace std;

int main() {
    string texto = "Ola, mundo!";
    cout << texto.find("mundo") << endl; // Saída: 5
    texto.replace(0, 3, "Adeus");
    cout << texto << endl; // Adeus, mundo!
    return 0;
}

Aula 33: Trabalhando com Listas

Listas são coleções mutáveis e dinâmicas.

  • .append(): Adiciona um item ao final da lista.
  • .remove(): Remove um item.
  • .sort(): Ordena os elementos da lista.

Listas em Python

letras_acertadas = []
letras_acertadas.append('a')
letras_acertadas.append('b')
print(letras_acertadas) # Saída: ['a', 'b']

palavra_secreta = "gato"
tentativa = input("Digite uma letra: ")
if tentativa in palavra_secreta:
    letras_acertadas.append(tentativa)

Listas (ArrayList) em Java

import java.util.ArrayList;

public class ListasJava {
    public static void main(String[] args) {
        ArrayList<String> letrasAcertadas = new ArrayList<>();
        letrasAcertadas.add("a");
        letrasAcertadas.add("b");
        System.out.println(letrasAcertadas); // [a, b]
    }
}

Listas (std::vector) em C++

#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<string> letrasAcertadas;
    letrasAcertadas.push_back("a");
    letrasAcertadas.push_back("b");
    for(string l : letrasAcertadas) {
        cout << l << " ";
    }
    return 0;
}
