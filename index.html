Aula 32: Métodos de Manipulação de Strings

As cadeias de caracteres em Python fornecem métodos nativos otimizados para rápida busca e modificação de textos:

  • .find(subTexto): Localiza o índice inicial da subcadeia. Retorna -1 caso o padrão não exista.
  • .count(padrão): Varre o texto e calcula a contagem total de ocorrências de determinado caractere ou palavra.
  • .upper() & .lower(): Converte toda a string para maiúsculas ou minúsculas, fundamental para comparação insensível a maiúsculas/minúsculas.
  • .replace(antigo, novo): Garante a substituição de trechos de texto sem alterar a string original diretamente.

🔒 Imutabilidade: Lembre-se de que Strings em Python, Java e C++ são imutáveis. Métodos como .upper() ou .replace() retornam uma nova cópia do texto sem alterar a variável original.

Exemplo Prático em Python (Strings)

Exemplo de extração e tratamento de dados de uma frase utilizando múltiplos métodos integrados:

texto = "Desenvolvimento de Sistemas"

# Busca de índice e contagem
posicao = texto.find("Sistemas")     # Retorna: 19
frequencia = texto.count("e")        # Retorna: 5

# Normalização e Substituição
texto_upper = texto.upper()          # "DESENVOLVIMENTO DE SISTEMAS"
novo_texto = texto.replace("Sistemas", "Web") # "Desenvolvimento de Web"

print(f"Posição: {posicao} | Ocorrências de 'e': {frequencia}")
print(f"Texto Modificado: {novo_texto}")

📌 Detalhamento: A indexação em Python é baseada em zero (0). O caractere 'D' está no índice 0, enquanto a palavra "Sistemas" inicia exatamente no índice 19.

Comparativo de Strings: Java & C++

Entender a equivalência dos métodos de string em linguagens compiled melhora a portabilidade do código:

// --- JAVA ---
String texto = "Desenvolvimento de Sistemas";
int pos = texto.indexOf("Sistemas");                 // Retorna 19
String novo = texto.replace("Sistemas", "Web");     // Substitui ocorrências
boolean contém = texto.contains("Sistemas");         // Retorna true

// --- C++ ---
#include <iostream>
#include <string>

std::string texto = "Desenvolvimento de Sistemas";
size_t pos = texto.find("Sistemas");                 // Retorna 19
texto.replace(pos, 8, "Web");                        // Substitui 8 caracteres

⚡ Performance: Em C++, métodos como replace atuam diretamente na memória (mutável), enquanto Java e Python alocam novas instâncias na memória Heap.

Aula 33: Estruturas de Dados (Listas)

O Desafio de Isabele (Jogo da Forca): Isabele precisa gerenciar o estado da palavra secreta e exibir o progresso do jogador sem perder os dados originais.

  • Natureza Dinâmica: Diferente de arrays tradicionais com tamanho fixo, as listas em Python se expandem ou contraem conforme necessário.
  • Indexação Direta: Cada posição armazena um caractere ou estado (ex: '_' para oculto e letras para palpites certos).
  • Mutabilidade: Permite modificar o valor de posições específicas individualmente através dos seus índices.

🧩 Aplicações de Listas: Gerenciamento de carrinhos de compras, filas de atendimento, dados de sensores e pontuações de jogos.

Lógica do Jogo da Forca com Listas

Análise do fluxo de dados para controle de estados do jogo através de listas contíguas:

1. Inicialização de Estado:
   palavra_secreta = "python"
   progresso = ['_', '_', '_', '_', '_', '_']

2. Atualização por Posição (Acerto da letra 'p' no Índice 0):
   progresso[0] = 'p'

   if '_' not in progresso: print("Você Venceu!")

Métodos Cruciais para Listas em Python

Principais operações para inserção, remoção e ordenação de dados em listas dinâmicas:

  • .append(item): Insere um novo elemento no final da lista com complexidade de tempo constante O(1).
  • .insert(índice, item): Adiciona um elemento em uma posição específica deslocando os subsequentes.
  • .remove(item): Localiza e apaga a primeira ocorrência do valor especificado.
  • .pop(índice): Remove e retorna o elemento armazenado no índice indicado.
  • .sort() / .reverse(): Reorganiza os elementos em ordem alfabética/numérica ou inverte a lista.

📏 Tamanho com len(): A função nativa len(lista) informa instantaneamente a quantidade total de itens armazenados na estrutura.

Exemplo Prático em Python (Listas)

Implementação de lógica completa para armazenamento de palpites e controle de histórico de jogadas:

historico_tentativas = []
palavra_secreta = "python"

# Adicionando tentativas com verificação
tentativa = input("Digite uma letra: ").lower()

if tentativa not in historico_tentativas:
    historico_tentativas.append(tentativa)
    if tentativa in palavra_secreta:
        print(f"A letra '{tentativa}' está na palavra!")
    else:
        print(f"A letra '{tentativa}' não existe na palavra.")
else:
    print("Você já tentou essa letra!")

print("Histórico de Palpites:", historico_tentativas)

⚙️ Controle de Fluxo: O método .append() assegura que cada palpite seja registrado no histórico sem duplicar entradas indesejadas.

Listas Dinâmicas em Java (ArrayList)

Em Java, coleções flexíveis utilizam a classe ArrayList do pacote java.util:

import java.util.ArrayList;

public class JogoForca {
    public static void main(String[] args) {
        // Declaração de lista dinâmica de Strings
        ArrayList<String> historico = new ArrayList<>();

        // Adição e verificação de itens
        historico.add("p");
        historico.add("y");
        
        boolean contem = historico.contains("p"); // Retorna true
        int tamanho = historico.size();           // Retorna 2

        System.out.println("Tamanho do Histórico: " + tamanho);
    }
}

☕ Java Generics: O uso de <String> garante a segurança do tipo (Type Safety), prevenindo erros de compilação.

Listas Dinâmicas em C++ (std::vector)

Em C++, a estrutura equivalente para contêineres dinâmicos e contíguos de memória é o std::vector:

#include <iostream>
#include <vector>
#include <string>

int main() {
    // Declaração do vector contíguo
    std::vector<std::string> historico;

    // Adição de itens no final do contêiner
    historico.push_back("p");
    historico.push_back("y");

    std::cout << "Itens armazenados: " << historico.size() << std::endl;
    std::cout << "Primeiro item: " << historico[0] << std::endl;

    return 0;
}

🚀 Gestão de Memória: O std::vector gerencia o redimensionamento do array na memória de forma automática durante a execução.
