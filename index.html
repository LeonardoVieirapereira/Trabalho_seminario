Aula 32: Contexto e Problematização

O Desafio de Carlos: Como desenvolvedor iniciante, Carlos precisa processar grandes volumes de texto para extrair informações específicas e realizar análises estatísticas.

  • Busca de Padrões: Localizar a posição exata de caracteres e palavras.
  • Contagem de Frequência: Saber quantas vezes um termo aparece no texto.
  • Normalização de Dados: Padronizar o texto (maiúsculas/minúsculas) para comparações sem erros de digitação.

Aula 32: Principais Métodos de Strings

A manipulação de strings é indispensável para validações e análise de textos em sistemas corporativos:

  • .find() / .index(): Retorna o índice numérico da primeira ocorrência de uma sub-string.
  • .count(): Calcula a frequência exata de um caractere ou palavra.
  • .upper() & .lower(): Converte a string para maiúsculas ou minúsculas (essencial para comparação de dados).
  • .replace(antigo, novo): Substitui sequências de texto por novos valores.

Exemplo Prático em Python (Strings)

Veja como executar operações essenciais em Python com poucas linhas de código:

# Declaração da String
texto = "Desenvolvimento de Sistemas"

# Executando os métodos da Aula 32
print(texto.find("Sistemas"))        # Saída: 19 (posição inicial)
print(texto.count("e"))               # Saída: 5 (frequência da letra 'e')
print(texto.upper())                 # Saída: DESENVOLVIMENTO DE SISTEMAS
print(texto.replace("Sistemas", "Web")) # Saída: Desenvolvimento de Web

Comparativo de Strings: Java & C++

A mesma lógica aplicada em outras linguagens orientadas a objetos e compiladas:

// --- JAVA ---
String texto = "Desenvolvimento de Sistemas";
int pos = texto.indexOf("Sistemas"); // 19
String novo = texto.replace("Sistemas", "Web");
System.out.println(texto.toUpperCase());

// --- C++ ---
#include <iostream>
#include <string>
std::string texto = "Desenvolvimento de Sistemas";
size_t pos = texto.find("Sistemas"); // 19
texto.replace(pos, 8, "Web");

Aula 33: Estruturas de Dados (Listas)

O Desafio de Isabele (Jogo da Forca): Como armazenar e atualizar o progresso de um jogo mantendo a estrutura da palavra secreta?

  • Listas em Python: São coleções mutáveis e dinâmicas que armazenam múltiplos itens em uma só variável.
  • Conceito de Índices: Cada elemento possui uma posição que começa em 0.
  • Evolução do Estado: Substiuição de underscores (_) pelas letras acertadas pelo jogador.

Lógica do Jogo da Forca com Listas

Representação prática do acompanhamento de progresso com a palavra "python":

1. Inicialização com Underscores:
   palavra_secreta = "python"
   progresso = ['_', '_', '_', '_', '_', '_']

2. O jogador adivinha a letra 'p' (Índice 0):
   progresso[0] = 'p' -> ['p', '_', '_', '_', '_', '_']

3. O jogador adivinha a letra 'o' (Índice 4):
   progresso[4] = 'o' -> ['p', '_', '_', '_', 'o', '_']

Métodos Cruciais para Listas em Python

Operações de manipulação dinâmica de coleções:

  • .append(item): Adiciona um novo elemento ao final da lista.
  • .remove(item): Remove a primeira ocorrência do valor especificado.
  • .sort(): Reorganiza os elementos em ordem alfabética ou numérica.
  • len(lista): Retorna a quantidade total de elementos dentro da lista.

Exemplo Prático em Python (Listas)

Código para armazenar palpites e gerenciar os acertos do jogador:

# Criando uma lista vazia de letras acertadas
letras_acertadas = []

# Adicionando elementos dinamicamente
letras_acertadas.append('p')
letras_acertadas.append('y')
print("Acertos:", letras_acertadas) # Saída: ['p', 'y']

# Verificando existência com o operador 'in'
palavra_secreta = "python"
tentativa = input("Digite uma letra: ").lower()

if tentativa in palavra_secreta:
    letras_acertadas.append(tentativa)

Listas Dinâmicas em Java (ArrayList)

Em Java, utilizamos a classe ArrayList para criar listas com tamanho dinâmico:

import java.util.ArrayList;

public class JogoForca {
    public static void main(String[] args) {
        // Criando uma lista de Strings
        ArrayList<String> letrasAcertadas = new ArrayList<>();

        // Adicionando elementos
        letrasAcertadas.add("p");
        letrasAcertadas.add("y");

        System.out.println("Progresso: " + letrasAcertadas);
    }
}

Listas Dinâmicas em C++ (std::vector)

Em C++, a estrutura equivalente para listas redimensionáveis é o std::vector:

#include <iostream>
#include <vector>
#include <string>

int main() {
    // Criando um vector dinâmico
    std::vector<std::string> letrasAcertadas;

    // Adicionando elementos com push_back
    letrasAcertadas.push_back("p");
    letrasAcertadas.push_back("y");

    std::cout << "Tamanho da lista: " << letrasAcertadas.size();
    return 0;
}
